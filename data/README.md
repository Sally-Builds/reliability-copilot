# Demo data

All data here is **synthetic**. It was generated by `scripts/seed.py` and shaped
like real production postmortems (failovers, deploy regressions, traffic spikes,
cert expiries, queue backlogs, cache stampedes).

- `incidents.json` — 250 incidents. Five are hand-authored to match
  `evals/golden-set.json` exactly; the rest are generated from archetype templates.
- Regenerate any time: `python3 scripts/seed.py` (deterministic seed, same output).

Never commit real incident data, credentials, or customer information here.
